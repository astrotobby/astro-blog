# Background music (royalty-free, zero-budget)

Drop one or more **royalty-free / CC0** audio tracks here (`.mp3`, `.m4a`,
`.wav`, `.ogg`). The pipeline auto-picks one per day and ducks it under the
voiceover (`music_volume` in `config.yaml`). If this folder is empty, videos
render **without** music — no fake/placeholder audio is ever added.

Commit the track files to the repo so the GitHub Action can use them.

### Free, license-clear sources (no attribution headaches)
- **Pixabay Music** — https://pixabay.com/music/ (free, no attribution required)
- **YouTube Audio Library** — Studio → Audio Library → filter "No attribution"
- **Free Music Archive (CC0)** — https://freemusicarchive.org/ (filter CC0)
- **Incompetech (CC-BY)** — https://incompetech.com/ (attribution required — add it
  to your post descriptions if you use these)

### Recommendation
Use 3–5 short, low-energy instrumental loops so consecutive posts don't all
sound identical. Keep them under ~2 min; the pipeline loops them to fit.
